# Skills Directory

Skills are modular knowledge and workflow packages under `.claude/skills/`.

## Included Core Skills

| Skill | Purpose |
|-------|---------|
| `mgmt-principles/` | Self-review checklist (`GP1–GP7`, `OP1–OP4`, `ARCH1–ARCH3`) and `/review-principles` workflow |
| `explanatory-integrity/` | Mandatory closing plain-language summary (`👵 옆집 할머니도 알아들을 수 있게 요약` / `👵 Plain-Language Summary`) |
| `long-run-discipline/` | Discipline for multi-step, long-running engineering and research execution |

## Adding Domain Skills

Create a subdirectory `<skill-name>/SKILL.md` with YAML frontmatter (`name`, `description`) and instructions. Domain skills are part of the optional periphery (`ARCHITECTURE.md`) and can be added or removed without affecting the portable core.
