# Bob — Workspace

Personal workspace for `bob`. Artifacts here use the same frontmatter schema as `content/` and auto-set `owner: bob`.

## Structure

- `profile.md` — Role, domains, and repository ownership
- `inbox/` — Raw intake items (`./hey inbox list --workspace bob`)
- `logs/` — Daily worklogs (`YYYY-MM-DD.md`)
- `ideas/` — Raw ideas awaiting promotion (`/idea`, `/promote`)
- `memory/` — Persistent context notes
