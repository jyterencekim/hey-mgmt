# Alice — Workspace

Personal workspace for `alice`. Artifacts here use the same frontmatter schema as `content/` and auto-set `owner: alice`.

## Structure

- `profile.md` — Role, domains, and repository ownership
- `inbox/` — Raw intake items (`./hey inbox list --workspace alice`)
- `logs/` — Daily worklogs (`YYYY-MM-DD.md`)
- `ideas/` — Raw ideas awaiting promotion (`/idea`, `/promote`)
- `memory/` — Persistent context notes
